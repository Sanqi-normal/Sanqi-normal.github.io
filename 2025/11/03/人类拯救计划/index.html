好想成为人类啊

收入

继续量化项目，同时尝试寻找别的短期收入渠道，能自主维持这段时间的开销最好。

学习

我没有办法肯定自己一定能赚到钱退学。我不能吊到金融这一条路上吊死，我必须努力补补过去漏掉的和学的不深入的知识，同时维持学习习惯，每天保持两个小时以上的学习时间，为复学学习回归正轨做准备。

学习内容及顺序：

  • 编程语言： C
    C++
    python

  • 导论：计算机图形学、图像处理、计算机视觉
    人工智能、自然语言处理
    操作系统
    信息、网络
    计算机组成结构

  • 基础：数据库
    程序设计
    算法
    数字逻辑
    编译原理

  • 其他：英语六级
    CSP认证

生活

饮食

有了更多菜和资金就能吃更多好吃的

居住

收拾干净屋子，然后尽可能添加想到的装饰。

运动

每天早起和傍晚出去散步/骑自行车转两圈，周末下午去打乒乓球。
